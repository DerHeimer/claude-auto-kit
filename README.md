# claude-auto-kit

Personal Claude Code plugin marketplace. Contains `project-pipeline` and skills collected from public sources (each skill names its source and license).

Maintained automatically by a weekly task. Only skills (Markdown instructions) are added automatically — no hooks, MCP servers or executables.

`project-pipeline` also calls skills from these separately installed plugins: `superpowers@claude-plugins-official`, `ui-ux-pro-max@ui-ux-pro-max-skill`, `diagram-design@diagram-design`.

## Install

```
claude plugin marketplace add DerHeimer/claude-auto-kit
claude plugin install auto-kit@auto-kit
```
